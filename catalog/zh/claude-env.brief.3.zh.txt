# Claude Code 环境变量 一句话说明（第 4 部分）
CLAUDE_CODE_USER_DIALOG_TIMEOUT_MS | 远程确认框等待多久后自动取消
CLAUDE_REMOTE_CONTROL_SESSION_NAME_PREFIX | 远程控制会话名称的前缀
CLAUDE_CODE_DISABLE_FEATURE_FLAGS | 不拉取功能开关，部分功能会不可用
CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY | 不再弹出满意度调查
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC | 关闭更新检查、遥测等非必要联网
CLAUDE_CODE_ATTRIBUTION_HEADER | 设为 0 去掉系统提示开头的版本标记，部分中转更省钱
CLAUDE_CODE_ENABLE_SHARE_BUNDLE | /share 保存到本地，不发送给 Anthropic
CLAUDE_CODE_HIDE_CWD | 启动画面不显示目录，录屏时保护隐私
CLAUDE_CODE_SEND_FEEDBACK | 是否允许 Claude 起草反馈
CLAUDE_CODE_SKIP_PROMPT_HISTORY | 不保存提示历史和会话记录
DISABLE_ERROR_REPORTING | 不上报错误信息
DISABLE_TELEMETRY | 不发送使用统计
DO_NOT_TRACK | 不发送使用统计（通用写法）
DISABLE_FEEDBACK_COMMAND | 关闭 /feedback、/bug 和 /share
DISABLE_GROWTHBOOK | 不拉取功能开关（旧写法）
IS_DEMO | 演示模式：隐藏邮箱和组织名
BETA_TRACING_ENDPOINT | 详细追踪数据发送到这个地址
CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL | 调查结果发到你自己的监控系统
CLAUDE_CODE_ENABLE_TELEMETRY | 开启 OpenTelemetry 监控数据采集
CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH | 监控数据中每段内容最多多长
CLAUDE_CODE_OTEL_DIAG_STDERR | 监控配置出错时在终端显示错误
CLAUDE_CODE_OTEL_FLUSH_TIMEOUT_MS | 发送监控数据的超时时间
CLAUDE_CODE_OTEL_HEADERS_HELPER_DEBOUNCE_MS | 多久刷新一次监控请求头
CLAUDE_CODE_OTEL_SHUTDOWN_TIMEOUT_MS | 退出时等待监控数据发完的时间
CLAUDE_CODE_PROPAGATE_TRACEPARENT | 经代理时传递追踪 ID，便于串联请求
ENABLE_BETA_TRACING_DETAILED | 开启包含内容的详细追踪
OTEL_ATTRIBUTE_VALUE_LENGTH_LIMIT | 监控属性值的最大长度
OTEL_LOG_ASSISTANT_RESPONSES | 监控日志中记录模型回复
OTEL_LOG_MANAGED_SETTINGS | 监控日志中记录托管设置（已脱敏）
OTEL_LOG_RAW_API_BODIES | 监控日志中记录完整的 API 请求和响应
OTEL_LOG_TOOL_CONTENT | 监控追踪中记录工具输出内容
OTEL_LOG_TOOL_DETAILS | 监控中记录工具参数和错误详情
OTEL_LOG_USER_PROMPTS | 监控中记录你输入的提示
OTEL_METRICS_INCLUDE_ACCOUNT_UUID | 设为 false 后监控指标不含账号 ID
OTEL_METRICS_INCLUDE_ENTRYPOINT | 监控指标中包含会话入口
OTEL_METRICS_INCLUDE_REPOSITORY | 监控指标中包含仓库信息
OTEL_METRICS_INCLUDE_RESOURCE_ATTRIBUTES | 设为 false 后不附加资源属性标签
OTEL_METRICS_INCLUDE_SESSION_ID | 设为 false 后监控指标不含会话 ID
OTEL_METRICS_INCLUDE_VERSION | 监控指标中包含版本号
CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE | 用 Homebrew、WinGet 安装时自动升级
DISABLE_AUTOUPDATER | 关闭自动更新，仍可手动 claude update
DISABLE_UPDATES | 禁止任何更新，包括手动更新
FORCE_AUTOUPDATE_PLUGINS | 主程序不自动更新时，插件仍自动更新
DISABLE_INSTALLATION_CHECKS | 不再提示安装位置相关的警告
CLAUDE_CODE_AUTOMOUNT_ROOTS | 查找配置时跳过这些挂载目录，避免卡住
CLAUDE_CODE_GIT_BASH_PATH | Git Bash 的位置，找不到 bash 时填写（Windows）
CLAUDE_CODE_PLUGIN_CACHE_DIR | 插件存放在哪个目录
CLAUDE_CODE_PLUGIN_DIRS | 本次会话额外加载的插件目录
CLAUDE_CODE_PLUGIN_SEED_DIR | 预装插件的只读目录，适合容器镜像
CLAUDE_CODE_PROJECT_DIR_NAME | 会话记录保存在哪个项目目录名下
CLAUDE_CODE_SHELL | 命令使用哪个 Shell，只支持 bash 或 zsh
CLAUDE_CODE_TMPDIR | 临时文件放在哪个目录
CLAUDE_CONFIG_DIR | 配置目录位置，可用来隔离多个账号
CLAUDE_CODE_DISABLE_DANGEROUS_RM_TIMEOUT | 删除关键目录时不再限时拒绝，改为确认
CLAUDE_CODE_DISABLE_INLINE_SHELL_RM_PROMPT | 不再检查 bash -c 脚本里的删除命令
CLAUDE_CODE_DISABLE_MOUNTED_DRIVE_RM_PROMPT | 删除 U 盘等挂载盘上的文件不再确认
CLAUDE_CODE_DISABLE_POWERSHELL_CMD_RM_DENY | 关闭 PowerShell 删除系统目录的保护
CLAUDE_CODE_DISABLE_SUBSTITUTION_RM_PROMPT | 不再检查 rm -rf "$(pwd)" 这类删除
CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS | 危险删除也不再确认，非常危险
CLAUDE_CODE_RESTRICTED | 以受限模式启动
CLAUDE_CODE_SCRIPT_CAPS | 限制某些脚本每个会话能运行几次
CLAUDE_CODE_SUBPROCESS_ENV_SCRUB | 子进程拿不到你环境变量里的密钥
CLAUDE_CODE_AUTO_CONNECT_IDE | 是否自动连接 IDE
CLAUDE_CODE_IDE_HOST_OVERRIDE | 连接 IDE 使用的地址
CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL | 不自动安装 IDE 插件
CLAUDE_CODE_IDE_SKIP_VALID_CHECK | IDE 已打开但连不上时开启
CLAUDE_CODE_DEBUG_LOGS_DIR | 调试日志写到哪个文件
CLAUDE_CODE_DEBUG_LOG_LEVEL | 调试日志记录到什么详细程度
CLAUDE_CODE_CONFIG_LOCK_WAIT_MS | 修改 MCP 配置时等待文件锁多久
CLAUDE_CODE_SAFE_MODE | 安全模式：不加载任何自定义配置，用于排查问题
CLAUDE_CODE_STARTUP_FAILURE_RESULTS | 启动失败时输出原因（JSON 流模式）
CLAUDE_CODE_YOU_SHOULD_KNOW_DEBUG | 显示 You should know 的检查记录
DEBUG | 开启调试模式，写入详细日志
ANTHROPIC_ORGANIZATION_ID | 身份联合登录使用的组织 ID
ANTHROPIC_FEDERATION_RULE_ID | 身份联合登录使用的规则 ID
CLAUDE_CODE_PROCESS_WRAPPER | 用企业启动器包裹后台进程
CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST | 宿主平台设置，忽略你自己的服务商配置
DISABLE_DOCTOR_COMMAND | 隐藏 /doctor 检查命令
DISABLE_EXTRA_USAGE_COMMAND | 隐藏购买额外用量的命令
DISABLE_INSTALL_GITHUB_APP_COMMAND | 隐藏 /install-github-app 命令
DISABLE_LOGIN_COMMAND | 隐藏 /login 命令
CLAUDECODE | 由 Claude Code 自动设置，无需手动填写
CLAUDE_CODE_CHILD_SESSION | 由 Claude Code 自动设置，无需手动填写
CLAUDE_CODE_MESSAGING_SOCKET | 由 Claude Code 自动设置，不要手动填写
CLAUDE_CODE_MESSAGING_TOKEN | 由 Claude Code 自动设置，不要手动填写
CLAUDE_CODE_RESUME_HINT_COMMAND | 退出时提示恢复会话所用的命令名
CLAUDE_CODE_SESSION_ID | 由 Claude Code 自动设置，无需手动填写
CLAUDE_EFFORT | 由 Claude Code 自动设置，无需手动填写
CLAUDE_JOB_DIR | 由 Claude Code 自动设置，无需手动填写
CLAUDE_PID | 由 Claude Code 自动设置，无需手动填写
