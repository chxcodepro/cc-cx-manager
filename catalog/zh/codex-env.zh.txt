# Codex ~/.codex/.env 中文叠加层（对应 Codex CLI 0.170.0，来源 learn.chatgpt.com/docs/config-file/environment-variables 与 codex-rs/arg0/src/lib.rs）
# .env 的加载规则（已核对源码）：
#   - 只读取 CODEX_HOME/.env（默认 ~/.codex/.env），项目目录里的 .env 不会被读取
#   - 以 CODEX_ 开头的变量（不区分大小写）一律忽略，必须在系统环境变量中设置
#   - 其他变量会写入 Codex 进程环境，并覆盖同名的系统环境变量；无法解析的行会被跳过

@category refs | config.toml 引用的变量 | 5 | 根据 config.toml 中 model_providers 的 env_key / env_http_headers，以及 mcp_servers 的 bearer_token_env_var / env_vars / env_http_headers 自动列出。Codex 启动时会把 .env 载入进程环境，所以服务商 API Key 可以直接写在这里，不必设置系统环境变量。
@category auth | 认证与身份 | 10 | 工作负载身份（Workload Identity）联合认证相关变量，用于在 CI / 云环境中免密钥登录 OpenAI。
@category network | 网络与证书 | 20 | 代理与自定义 CA 证书。公司网络有 TLS 拦截或使用自签名证书时需要配置。
@category debug | 日志与调试 | 30 | 排查问题时调整日志详细程度。
@category sysenv | 仅系统环境变量（.env 中无效） | 40 | 以下变量都以 CODEX_ 开头，Codex 会忽略 .env 中的这些变量，必须在系统环境中设置。\nWindows：设置 → 系统 → 关于 → 高级系统设置 → 环境变量；或在 PowerShell 中运行 [Environment]::SetEnvironmentVariable('变量名', '值', 'User')，然后重新打开终端。\nmacOS / Linux：在 ~/.zshrc 或 ~/.bashrc 中加入 export 变量名="值"，然后重新打开终端或执行 source。
