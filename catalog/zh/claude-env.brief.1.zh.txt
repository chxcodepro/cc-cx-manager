API_FORCE_IDLE_TIMEOUT | 输出中断多久算超时，设为 0 不限制（适合本地模型）
CLAUDE_CODE_CERT_STORE | 信任哪些 CA 证书，公司网络有自签证书时要含 system
CLAUDE_CODE_CLIENT_KEY_PASSPHRASE | 客户端证书私钥的密码
CLAUDE_CODE_DISABLE_MTLS_RELOAD_ON_STALE_CONNECTION | 连接出错时不重新读取客户端证书
CLAUDE_BYTE_STREAM_IDLE_TIMEOUT_MS | 响应卡住多久后断开重连
CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK | 流式请求失败后不再改用普通请求重试
CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS | 中转报 400 错误时开启，去掉实验性功能
CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS | 网关不支持结构化输出时开启
CLAUDE_CODE_EXTRA_BODY | 给每个模型请求附加额外参数（JSON）
CLAUDE_CODE_GATEWAY_HINT_HEADERS | 是否向网关发送请求类型提示头
CLAUDE_CODE_GZIP_REQUEST_BODIES | 设为 0 关闭请求压缩
CLAUDE_CODE_MAX_RETRIES | 请求失败时最多重试几次
CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES | 普通请求超时后最多重发几次
CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS | 服务器过载时，第一次重试前等多久
CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS | 下载插件市场最多等多久
CLAUDE_CODE_PLUGIN_PREFER_HTTPS | 用 HTTPS 下载插件，没配 SSH 密钥时有用
CLAUDE_CODE_PROXY_RESOLVES_HOSTS | 让代理负责域名解析
CLAUDE_CODE_RETRY_WATCHDOG | 服务繁忙时无限重试，适合无人值守
CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS | 服务繁忙时每个请求最多等多久
CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS | 等额度恢复时多久检查一次
CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS | 快速模式检查被网络拦截时，仍视为可用
CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK | 跳过快速模式可用性检查
CLAUDE_ENABLE_BYTE_WATCHDOG | 强制开启或关闭响应卡住检测
CLAUDE_ENABLE_STREAM_WATCHDOG | 强制开启或关闭输出卡住检测
CLAUDE_STREAM_IDLE_TIMEOUT_MS | 输出卡住多久后断开，最少 5 分钟
BASH_DEFAULT_TIMEOUT_MS | 命令默认运行多久超时，默认 2 分钟
BASH_MAX_TIMEOUT_MS | 命令最长允许运行多久，默认 10 分钟
BASH_MAX_OUTPUT_LENGTH | 命令输出最多读回多少字
CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR | 每条命令执行完都回到项目目录
CLAUDE_CODE_BASH_EDIT_DIFF | 是否显示命令改动了哪些文件
CLAUDE_CODE_DISABLE_ATTACHMENTS | @ 文件时只发送文件名，不发送内容
CLAUDE_CODE_DISABLE_FILE_MENTIONS | @ 文件时只给路径，让 Claude 自己去读
CLAUDE_CODE_DISABLE_WEB_FETCH | 关闭网页抓取工具（搜索仍可用）
CLAUDE_CODE_DISABLE_WINDOWS_SHELL_LAUNCHER | 直接启动 PowerShell，不经过 cmd（仅 Windows）
CLAUDE_CODE_FILE_READ_MAX_OUTPUT_TOKENS | 读取单个文件最多多少 token，大文件可调大
CLAUDE_CODE_GLOB_HIDDEN | 设为 false 后查找文件时跳过隐藏文件
CLAUDE_CODE_GLOB_NO_IGNORE | 设为 false 后查找文件时跳过 .gitignore 忽略的文件
CLAUDE_CODE_GLOB_TIMEOUT_SECONDS | 查找文件和搜索内容最多等几秒
CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION | 每个会话最多联网搜索几次
CLAUDE_CODE_PERFORCE_MODE | 未 p4 edit 的只读文件不允许修改
CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY | PowerShell 遵守本机的脚本执行策略
CLAUDE_CODE_SHELL_PREFIX | 所有命令前面加上这个前缀，如审计脚本
CLAUDE_CODE_TOOL_MEMORY_CGROUP_EXCLUDE | 哪些进程不受内存上限限制（仅 Linux）
CLAUDE_CODE_TOOL_MEMORY_LIMIT | 命令最多能用多少内存，如 4G（仅 Linux）
CLAUDE_CODE_USE_POWERSHELL_TOOL | 是否启用 PowerShell 工具（Windows）
CLAUDE_CODE_WARN_DISK_FREE_GIB | 磁盘剩余空间低于多少 GiB 时提醒
CLAUDE_CODE_WARN_MEMORY_FREE_GIB | 可用内存低于多少 GiB 时提醒（仅 Linux）
CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS | 同一网页的抓取结果缓存多久
CLAUDE_CODE_WEBFETCH_DEADLINE_MS | 抓取一个网页最多等多久
CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR | 每小时恢复多少次搜索额度
CLAUDE_ENV_FILE | 每条命令前先运行的脚本，如激活 conda 环境
USE_BUILTIN_RIPGREP | 设为 0 改用系统安装的 rg
CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND | MCP 任务在前台等待结果，不转后台
CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH | MCP 工具说明最多发送多少字
CLAUDE_CODE_MCP_ALLOWLIST_ENV | MCP 服务器不再继承你全部的环境变量，更安全
CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS | MCP 调用运行多久后转入后台
CLAUDE_CODE_MCP_STARTUP_WAIT_MS | 非交互模式下等待 MCP 连接多久
CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT | MCP 工具无响应多久算失败
ENABLE_CLAUDEAI_MCP_SERVERS | 设为 false 不加载 claude.ai 上的 MCP 服务器
ENABLE_TOOL_SEARCH | 按需加载 MCP 工具，节省上下文
MAX_MCP_OUTPUT_TOKENS | MCP 工具返回内容最多多少 token
MCP_CLIENT_SECRET | MCP 服务器的 OAuth 客户端密钥
MCP_CONNECTION_NONBLOCKING | 设为 0 时，先等 MCP 连接好再开始

MCP_DISCOVERY_CACHE | 缓存远程 MCP 的工具列表，启动更快
MCP_DISCOVERY_CACHE_MAX_STALE_S | MCP 工具列表缓存最长保留多久
MCP_DISCOVERY_CACHE_TTL_S | MCP 工具列表缓存多久后在后台刷新
MCP_OAUTH_CALLBACK_PORT | MCP 登录回调使用的固定端口
MCP_PROTOCOL_NEGOTIATION | 是否尝试新版 MCP 协议
MCP_REMOTE_SERVER_CONNECTION_BATCH_SIZE | 同时连接多少个远程 MCP 服务器
MCP_SDK_GENERATION | 使用哪一代 MCP 客户端
MCP_SERVER_CONNECTION_BATCH_SIZE | 同时启动多少个本地 MCP 服务器

MCP_TOOL_TIMEOUT | MCP 工具最长运行多久
CLAUDE_ASYNC_AGENT_STALL_TIMEOUT_MS | 子代理多久没进展算卡住

CLAUDE_AGENT_SDK_MCP_NO_PREFIX | SDK 中的 MCP 工具不加名称前缀
