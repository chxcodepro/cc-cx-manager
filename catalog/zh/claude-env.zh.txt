# ---------------- 认证与 API ----------------
ANTHROPIC_API_KEY | API Key | auth | 以 X-Api-Key 请求头发送的 API Key。设置后即使已登录 Pro / Max / Team 等订阅，也会改用这个 Key 计费；交互模式下首次使用会询问是否批准。 | | 密钥建议放在系统环境变量或密码管理器中，避免写进会提交到仓库的项目设置 | s ;; ph=<YOUR_API_KEY>
ANTHROPIC_AUTH_TOKEN | Authorization 令牌 | auth | 自定义 Authorization 请求头的值（会自动加上 Bearer 前缀）。使用 LLM 网关或第三方中转服务时常用它代替 API Key。 | | | ;; s ;; ph=<YOUR_AUTH_TOKEN>
ANTHROPIC_BASE_URL | API 地址 | auth | 覆盖 API 接口地址，把请求转发到代理、网关或中转服务。自 2.1.196 起，指向非官方地址时 Remote Control 会被禁用。 | | 使用中转时填写服务商提供的地址 | ph=<YOUR_BASE_URL>
ANTHROPIC_CUSTOM_HEADERS | 自定义请求头 | auth | 附加到请求上的自定义请求头，格式为「名称: 值」，多个请求头用换行分隔。名称或值包含 HTTP 不允许的字符时请求会失败。 | | | ;; ex="X-Team: platform"
ANTHROPIC_BETAS | 额外 Beta 头 | auth | 逗号分隔的额外 anthropic-beta 请求头值，用于在 Claude Code 原生支持之前抢先启用某个 API Beta 功能。 | | | ;; tags=advanced ;; ex="context-1m-2025-08-07"
ANTHROPIC_PROFILE | Anthropic 配置档 | auth | 用于认证的 Anthropic 配置档名称，例如由 ant auth login 创建的配置档。 | | |
ANTHROPIC_ORGANIZATION_ID | 组织 ID（身份联合） | enterprise | 工作负载身份联合（Workload Identity Federation）使用的组织 ID，需与 ANTHROPIC_FEDERATION_RULE_ID 一起设置。 | | | ;; tags=enterprise
ANTHROPIC_FEDERATION_RULE_ID | 联合规则 ID | enterprise | 工作负载身份联合的规则 ID；与 ANTHROPIC_ORGANIZATION_ID 同时设置后，联合凭据优先于 /login 登录凭据。 | | | ;; tags=enterprise
ANTHROPIC_WORKSPACE_ID | 工作区 ID（身份联合） | enterprise | 联合规则作用于多个工作区时，指定令牌交换的目标工作区。 | | | ;; tags=enterprise
CLAUDE_CODE_API_KEY_HELPER_TTL_MS | API Key 脚本刷新间隔 | auth | 使用 apiKeyHelper 时重新获取凭据的间隔（毫秒）。 | | | ;; u=ms ;; ex=3600000
API_TIMEOUT_MS | 请求超时 | network | 每次 API 请求等待响应头的时间（毫秒），不限制之后流式输出的时长。默认 600000（10 分钟），最大 2147483647。 | | 网络慢或中转服务排队久时可适当调大 | u=ms ;; def="600000"
API_FORCE_IDLE_TIMEOUT | 流式空闲超时 | network | 覆盖流式响应 5 分钟无数据即中止的空闲超时。设为 0 关闭该超时（适合本地模型或很慢的网关两段输出间隔超过 5 分钟的情况）。 | | | ;; ex="0"

# ---------------- 推理与输出 ----------------
CLAUDE_CODE_ALWAYS_ENABLE_EFFORT | 总是发送推理强度 | thinking | 设为 1 后每个请求都带上 effort 参数，即使 Claude Code 不认识该模型 ID。通过网关或第三方以自定义名称提供模型时使用。 | | 使用中转且模型名不是官方 ID 时开启，否则 /effort 可能不生效
CLAUDE_CODE_DISABLE_ADAPTIVE_THINKING | 关闭自适应思考 | thinking | 设为 1 在 Opus 4.6 / Sonnet 4.6 上关闭自适应推理，改用 MAX_THINKING_TOKENS 控制的固定思考预算。对 Fable、Sonnet 5 及更新、Haiku 5.5、Opus 4.7 及更新的模型无效。 | | |
CLAUDE_CODE_DISABLE_ADVISOR_TOOL | 禁用顾问工具 | features | 设为 1 禁用顾问（advisor）工具：/advisor 不可用，advisorModel 被忽略。 | | |
