# Claude Code 环境变量 一句话说明（第 3 部分）
CLAUDE_CODE_EMIT_SESSION_STATE_EVENTS | 在输出流中加入会话状态事件（SDK 用）
CLAUDE_CODE_EXIT_AFTER_STOP_DELAY | 空闲多久后自动退出，适合自动化脚本
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS | 开启多个 Claude 协作的代理团队（实验）
CLAUDE_CODE_FORCE_SESSION_PERSISTENCE | 在会话里再启动 claude 时也保存记录
CLAUDE_CODE_FORK_SUBAGENT | 设为 0 关闭 Claude 自行分叉子任务
CLAUDE_CODE_FORWARD_SUBAGENT_TEXT | -p 输出中包含子代理的文字和思考
CLAUDE_CODE_GOAL_CHECKIN_MINUTES | 目标等待多少分钟后提醒 Claude 检查进度
CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS | 最多同时运行多少个子代理
CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH | 子代理最多嵌套几层，1 为不嵌套
CLAUDE_CODE_MAX_TURNS | 每次任务最多执行多少轮
CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS | -p 模式结束前最多等后台任务多久
CLAUDE_CODE_RESUME_INTERRUPTED_TURN | 上次中途中断时自动接着做
CLAUDE_CODE_RESUME_INTERRUPTED_TURN_MAX_AGE_MS | 中断超过这个时间就不再自动续接
CLAUDE_CODE_RESUME_PROMPT | 自动续接时发给 Claude 的话
CLAUDE_CODE_RESUME_SHOWS_CUT_OFF_CALLS | 续接时保留被中断的工具调用
CLAUDE_CODE_TASK_LIST_ID | 多个会话填同一个 ID 即可共享任务列表
CLAUDE_CODE_TRANSCRIPT_LOCAL_GC | 自动清理长会话的旧记录，避免文件过大
CLAUDE_CODE_WORKER_CHECKIN_SCHEDULE | 多久提醒 Claude 检查后台子代理
CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS | 工作流最多同时运行多少个代理
CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS | 工作流代理错开启动，提高缓存命中
MAX_STRUCTURED_OUTPUT_RETRIES | 输出不符合 JSON 格式时最多重试几次
TASK_MAX_OUTPUT_LENGTH | 已无效果，可以删除
CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS | 会话结束时的 hooks 最多运行多久
CLAUDE_CODE_STOP_HOOK_BLOCK_CAP | Stop hook 最多连续阻止结束几次
CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD | 也读取 --add-dir 目录里的 CLAUDE.md
CLAUDE_CODE_DISABLE_CLAUDE_MDS | 不读取任何 CLAUDE.md 和记忆
CLAUDE_CODE_DISABLE_GIT_INSTRUCTIONS | 去掉内置的 git 说明和状态，省上下文
CLAUDE_AUTOCOMPACT_PCT_OVERRIDE | 上下文用到百分之多少就压缩，只能调低
CLAUDE_CODE_AUTO_COMPACT_WINDOW | 上下文达到多少 token 时自动压缩
CLAUDE_CODE_DISABLE_1M_CONTEXT | 不使用 1M 上下文，最多 200K
CLAUDE_CODE_DISABLE_AUTO_MEMORY | 关闭自动记忆；设为 0 则强制开启
CLAUDE_CODE_DISABLE_FILE_CHECKPOINTING | 关闭后 /rewind 无法撤销代码改动
CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT | 不认识的模型不提前压缩上下文
CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS | 上下文超过多少 token 时空闲压缩才生效
CLAUDE_CODE_MAX_CONTEXT_TOKENS | 告诉 Claude Code 模型的上下文有多大
DISABLE_AUTO_COMPACT | 关闭自动压缩，仍可手动 /compact
DISABLE_COMPACT | 关闭所有压缩，包括 /compact
SLASH_COMMAND_TOOL_CHAR_BUDGET | 技能列表最多占用多少字
CLAUDE_CODE_DISABLE_ADVISOR_TOOL | 关闭顾问工具和 /advisor
CLAUDE_CODE_AUTO_MODE_SERVER | 设为 0 不让服务端审核自动模式操作
CLAUDE_CODE_DISABLE_BUNDLED_SKILLS | 不提供 Claude Code 自带的技能
CLAUDE_CODE_DISABLE_CFC_PROMPT | 宿主程序用：保留浏览器工具但省略说明
CLAUDE_CODE_DISABLE_PERMISSION_PROMPT_NOTIFY_HOOKS | 权限请求不再触发通知 hooks
CLAUDE_CODE_DISABLE_POLICY_SKILLS | 不加载系统预置的技能
CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK | ultrareview 在未信任目录也能运行，如 CI
CLAUDE_CODE_ENABLE_AUTO_MODE | 已无效果，可以删除
CLAUDE_CODE_ENABLE_BACKGROUND_PLUGIN_REFRESH | -p 模式下后台装好插件后立即生效
CLAUDE_CODE_ENABLE_CFC | 启动时开启或关闭 Chrome 浏览器集成
CLAUDE_CODE_ENABLE_FINE_GRAINED_TOOL_STREAMING | 工具参数边生成边传输，长文件写入不显得卡住
CLAUDE_CODE_ENABLE_TASKS | 设为 0 改用旧的 TodoWrite 任务工具
CLAUDE_CODE_ENABLE_TODO_TOOLS | 所有模型都提供任务清单工具
CLAUDE_CODE_EXPERIMENTAL_CODE_MODE | 以 Code Mode 启动会话（实验）
CLAUDE_CODE_NEW_INIT | /init 先问你要生成哪些文件
CLAUDE_CODE_PLUGIN_DIR_WATCH | 插件文件改动后是否自动重新加载
CLAUDE_CODE_PLUGIN_KEEP_MARKETPLACE_ON_FAILURE | 插件市场刷新失败时继续用旧版本，适合离线
CLAUDE_CODE_SIMPLE | 极简模式：只保留命令、读写文件工具
CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT | 使用完整还是精简的系统提示
CLAUDE_CODE_SYNC_PLUGIN_INSTALL | -p 模式下先等插件装好再开始
CLAUDE_CODE_SYNC_PLUGIN_INSTALL_TIMEOUT_MS | 等待插件安装的最长时间
CLAUDE_CODE_SYNC_SKILLS | 下载 claude.ai 账号里启用的技能
CLAUDE_CODE_SYNC_SKILLS_INSTALL_TIMEOUT_MS | SDK 重新同步技能的超时时间
CLAUDE_CODE_SYNC_SKILLS_WAIT_TIMEOUT_MS | 首次等待技能列表的最长时间
CLAUDE_CODE_BS_AS_CTRL_BACKSPACE | 退格键删除一个字还是整个单词
CLAUDE_CODE_ACCESSIBILITY | 显示终端原生光标，方便放大镜跟随
CLAUDE_AX_SCREEN_READER | 输出适合读屏软件的纯文本界面
CLAUDE_AX_PREPARK_MS | 读屏模式下写入新内容前稍等一下
CLAUDE_AX_STARTUP_QUIET_MS | 读屏模式下启动后稍等再显示界面
CLAUDE_CODE_ALT_SCREEN_FULL_REPAINT | 全屏模式出现残影时开启，每次整屏重绘
CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN | 不用全屏界面，保留终端原生滚动和搜索
CLAUDE_CODE_DISABLE_MOUSE | 全屏模式下不接管鼠标，可直接选中复制
CLAUDE_CODE_DISABLE_MOUSE_CLICKS | 全屏模式下只保留滚轮，不响应点击
CLAUDE_CODE_DISABLE_TERMINAL_TITLE | 不自动修改终端窗口标题
CLAUDE_CODE_DISABLE_VIRTUAL_SCROLL | 全屏模式滚动出现空白时开启
CLAUDE_CODE_ENABLE_AWAY_SUMMARY | 强制开启或关闭离开回来后的回顾
CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION | 设为 false 关闭输入框里的灰色建议
CLAUDE_CODE_FORCE_STRIKETHROUGH | 强制显示删除线效果

CLAUDE_CODE_NO_FLICKER | 开启全屏界面，消除闪烁
